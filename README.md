
# 🐦 Flappy Bird - Unity 2D Game

## 📌 About the Game
A 2D Flappy Bird game developed using Unity. Control the bird, avoid obstacles, and try to achieve the highest score!

## 🎮 Features
- 2D gameplay
- Bird movement and obstacle avoidance
- Collision detection
- Score system

## 🛠️ Technologies Used
- Unity
- C#
